No hay combobox/listbox/datalist propios adicionales en runtime; se cotejan AST, búsquedas, consumidores y SSR. No existen selectores de proveedor/compras/microinsumos futuros, horarios, prioridades o semanas en esta base. Usuarios son maestro con selector Rol, no catálogo de usuarios seleccionables. Concepto de gasto es texto libre Descripción; Concepto de costos sí es enum traducido y se inventaría. Lotes se eligen por code visible, no por fecha. Las categorías string usan label(), que puede traducir un código; el futuro comparador usa esa etiqueta sin renombrar el código.
